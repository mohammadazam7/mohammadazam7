# Portfolio site

Source for **[mohammadazam7.github.io/mohammadazam7](https://mohammadazam7.github.io/mohammadazam7/)**, the personal portfolio of Mohammad Azam, Data & Software Engineer.

- Single self-contained `index.html`: no build step, no dependencies to install
- Streaming-style layout: intro, viewer profiles, rows of work, career "seasons" with episodes
- Includes an interactive SQL console that queries the resume as tables
- Deployed with GitHub Pages from this `gh-pages` branch
